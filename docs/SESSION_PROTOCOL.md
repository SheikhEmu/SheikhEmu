## 1. عند افتتاح الجلسة — قبل أي عمل

1. **التجهيز الحتمي أولًا** (أول خطوة في كل جلسة قادمة، بأمر المالك
   D-43):

   ```sh
   cd <المستودع>
   sh tools/session_setup.sh
   . "$HOME/.sheikhemu-session-env.sh"
   ```

   الأداة تعيد تزويد كل ما يفقده التدوير، حتميًا وموثقًا المصدر:
   - **Rust** — عبر `~/.cargo/env` إن وُجد، وإلا تثبيت rustup
     (الم profile الأدنى، أداة `stable`)؛ وتتحقق من `cargo` و`rustc`
     ومكوّني `clippy` و`rustfmt`.
   - **ترويسات ALSA** — النظامية (`/usr/include/alsa`) إن وُجدت، وإلا
     عبر sudo بلا كلمة سر إن توفر، وإلا **حزمة debian مثبتة البصمة**
     (`libasound2-dev` ‏1.2.14-1+deb13u1، SHA256 ‏`dfa8e8a1…`) تُستخرج
     جذريًا (بلا جذر) إلى `~/.local/sheikhemu-alsa` مع ملف pkg-config
     يعمل — لتبني `se-frontend` (cpal) محليًا.
   - **رومات الفئة B** — من مصادرها الموثقة المثبتة commit لبعضها:
     `christopherpow/nes-test-roms` @ `95d8f621…` و
     `bbbradsmith/nes-audio-tests` @ `99ef107f…` إلى `~/SheikhEmuRoms`
     (خارج المستودع دائمًا)، مع بصمة SHA256 مثبتة للملفات الثلاثة
     (`nestest.nes` و`nestest.log` و`ppu_vbl_nmi.nes`) وختم provenance
     يُعاد كتابته كل تشغيل.

   أي **FAIL** من الأداة = لا عمل قبل حله أو الإبلاغ. الأداة تتحقق
   أيضًا من أن `~/SheikhEmuRoms` خارج شجرة المستودع، وأن `.gitignore`
   يحرس مدخلات الفئة B، وأن لا ملف `.nes` متتبَّع في المستودع.

2. **المزامنة القسرية مع البعيد** (لا بناء على أي لقطة قديمة أبدًا):

   ```sh
   git fetch origin
   git rev-parse origin main        # أو: git rev-parse origin/main
   git reset --hard origin/main
   git clean -fd                    # بلا -x: لا نمسّ ذاكرة target/
   git stash list                   # أي stash قديم يُفحص ضد البعيد
   ```

   الرأس البعيد المتوقع **يُعلَن في رسالة المالك التي تفتح الجلسة**
   (مثال جلسة 2026-11-15: `0a6f73a937ee712b51cbd196cb63cfa5cb4f4a97`).
   أي تعديلات محلية أو stash قديمة: تُفحص ضد البعيد، وإن كانت
   مستدرَكة (مستبدلة بعمل مدفوع) **تُرمى** — كما رُميت في هذه الجلسة
   stash مُوثقة بأنها مستدرَكة. أي اختلاف في SHA البعيد عن المتوقع =
   توقف وإبلاغ المالك قبل أي عمل.

3. **التحقق الكتابي قبل البدء:** رقم SHA البعيد مكتوب ومطابق،
   `git status` نظيف، و`git log origin/main..main --oneline | wc -l`
   يساوي صفرًا (لا عمل غير مدفوع — القاعدة D-15: GitHub هو المخزن
   المعمّر الوحيد).

## 2. أثناء الجلسة

- **الالتزامات بالإنجليزية**، دفعات صغيرة: كل بند بدفعته التوثيقية
  الخاصة بها (النمط المعتمد منذ M1).
- **توكن الدفع المؤقت:** يستخدم **متغير بيئة في أمر الدفع فقط** — لا
  يُكتب في أي ملف، ولا في رابط الـremote، ولا في تاريخ git؛ يحذفه
  المالك فور تأكيده اكتمال دفعات الجلسة. الأمر:

  ```sh
  git -c credential.helper='!f(){ printf "username=x-access-token\npassword=%s\n" "$GH_TOKEN"; }; f' \
      push origin main
  git ls-remote origin refs/heads/main   # التحقق: يطابق HEAD المحلي
  ```

- **الارتدادات الكاملة قبل أي دفع:** `make ci-local` كاملًا (fmt و
  clippy واختبارات workspace وtest-roms واللوحات وبوابة الطوب و
  apu-demo وأبواب الامتثال والحجم والذهبيات وpattern) + أبواب البند
  الخاصة (nestest حرفيًا وppu_vbl_nmi وsprite_hit متى مسّ التغيير
  مساسًا بصميًا).
- **أي إصلاح نواة** يُعرض على المالك **بدليله وأثره البصمي** (القيم
  القديمة/الجديدة والمدى المحصور وإثبات عدم تغيّر ما عداها) **قبل**
  تطبيقه — شرط M4.5 المستمر من D-37/D-42؛ أي انحراف بصمي خارج نقلة
  معتمدة = توقف وإبلاغ بالدليل.
- **رومات الفئة B لا تدخل أي التزام** — أبدًا، ولو للاختبار؛ تُشغَّل
  وتُراقب نتائجها فقط (SPEC §12.2)، ومسارها `~/SheikhEmuRoms`.

- **unpushed = 0** — أمر التحقق قبل الإبلاغ:

  ```sh

  ```

  Actions العامة — وتُسجَّل أرقامها في PROGRESS.md مع SHAs
  الالتزامات.
- **التوثيق** (DECISIONS.md / BLOCKERS.md / PROGRESS.md / EVIDENCE.md
  حسب البند) داخل دفعات الجلسة نفسها — لا يبقى توثيق غير مدفوع.
- **تقرير قصير بالعربية** للمالك: ما أُنجز، SHAs المدفوعة، أرقام CI
  ووظائفها، وما يلي. الجلسة تنتهي بحالة قابلة للبناء.
