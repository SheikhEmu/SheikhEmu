# SheikhEmu — مضاهاة NES مفتوحة المصدر، عربية، محلية 100%

**الشعار: مضاهاة بلا كلفة، بلا حسابات، بلا تتبع، بلا محتوى محمي.**

هذا مستودع المرحلتين **M0** (الأساس) و **M1** (النواة الصامتة): نواة 6502
تنفّذ **الأوامر الـ256 كلها** (151 موثّقة + 105 غير رسمية) بعدّ دورات
دقيق، ناقل ذاكرة NES حقيقي (RAM 2KiB بمراياها + خرائط NROM + سلوك
ناقل مفتوح موثّق)، متتاليات مقاطعات NMI/IRQ/RESET، ثوابت توقيت
NTSC/PAL/Dendy (مع تصحيح نسبة PAL الشهيرة 16:5)، محلل ترويسات
iNES/NES 2.0 كامل القواعد، وواجهة سطر أوامر عربية (`se-cli info` و
`se-cli run` بالبصمات وسجل تتبّع مرجعي)، مع كارتريدج اختباري مصنوع
ذاتيًا وأبواب امتثال آلية. كل الكود مكتوب من الصفر وفق التوثيق العام
للعتاد فقط — انظر `docs/LEGAL_POLICY.md` و `docs/SPEC.md`.

## البناء والتشغيل (كليًا دون شبكة)

```sh
cargo test --workspace        # 128 اختبارًا
cargo build --release -p se-cli
target/release/se-cli info tests/roms/hello.nes   # تقرير عربي كامل
target/release/se-cli run tests/roms/hello.nes --frames 600 --hash
                                # تنفيذ فعلي + بصمة حالة حتمية
make test-roms                # بناء كارتريدج الاختبار من المصدر
make gates                    # أبواب الامتثال
make golden                   # بوابة حتمية hello على 600 إطار
make ci-local                 # كل ما يشغله CI محليًا
tools/nestest_check.sh        # معايرة nestest (الملف خارج المستودع)
```

معايرة المرجع: سجل تتبّع CPU عندنا **مطابق بايتيًا** لسجل nestest
المرجعي (8991/8991 سطرًا) — راجع `docs/TIMING.md`.

## البنية

- `crates/se-core` — النواة: `timing` (مناطق التوقيت) + `cpu`
  (جدول 256 أمرًا + محرك 6502 كاملًا) + `bus` (خريطة ذاكرة NES) +
  `machine` (قشرة التنفيذ وعدّاد الدورات وبصمات الحالة) + `trace`
  (سجل التتبّع بصيغة المرجع).
- `crates/se-rom` — محلل iNES / NES 2.0 مع رسائل عربية وتحذيرات
  (DiskDude، الأس-المضاعِف، إزاحات RAM، تعارض البطارية).
- `crates/se-cli` — الواجهة العربية: `info` و`run`.
- `tools/` — `mini_asm` (مجمّع 6502 ثنائي التمرير)، `mkrom`، الأبواب،
  `check_golden` (بوابة الحتمية)، `nestest_check` (معايرة الجلسة).
- `tests/roms/` — hello.asm: كارتريدج اختباري مملوك بالكامل للمشروع.
- `tests/golden/` — بصمة hello على 600 إطار (روم منزلي ⇒ مسموح).
